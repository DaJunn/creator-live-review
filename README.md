# creator-live-review

把带货者一场、一天或指定多场直播整理为内部运营复盘：结果、货盘问题、公司侧收益测算，以及带货者、运营、选品的下场动作。

## 安装与使用

```bash
git clone https://github.com/DaJunn/creator-live-review.git \
  ~/.agents/skills/creator-live-review
```

对 AI 说：“复盘 XX 昨天直播”“XX 这场货盘有什么问题”“给 XX 出下场动作”。提供带货者、场次或日期，以及可用数据即可。

## 数据从哪里来

本仓库不带采集脚本，是复盘编排说明。

| 数据 | 使用方式 |
|---|---|
| 友望场次、商品明细 | 环境已有 `youwant` skill 时调用 |
| 微信小店订单 | 可用的 `wechat-store-order-stats` 或用户导出，用于核对 |
| 已有表格、文本 | 可直接分析；缺字段明确标注 |

上述配套依赖的安装与可用性需在当前环境核验。未安装时不能自动联网取数，但仍可复盘用户提供的数据。

## 输出与口径

输出关键结果、商品集中度与效率、证据支持的问题，以及分角色的下场动作。数据不足时保留可完成部分，不强行评好坏。

公司侧营收测算 = GMV × 佣金率 × (1−退货率) × MCN 分成；毛利润还需扣公司成本。优先使用实际参数，缺参数需要估算时采用 30% 佣金率、20% 退货率、40% MCN 分成，并注明“默认假设”。友望预估、后台实际与人工数据分别标识，未核对订单不能写成已核对。

完整工作流与验收要求见 [SKILL.md](SKILL.md)。需要直接采集视频号历史对比时可配合 `wechat-channels-history-review`；需要调整货架时可配合 `wechat-live-commodity-ops`。
